# Arquitectura

- WPF + .NET 8.
- `Models`: estado de archivos y proyectos.
- `Services`: parser, metadatos, escaneo, duplicados, proyecto, CSV y respaldo.
- TagLibSharp para lectura multiformato.
- Proyecto `.ammproj` JSON en v0.2 para máxima portabilidad y auditoría.
- Conectores externos desacoplados se incorporan desde v0.3.
