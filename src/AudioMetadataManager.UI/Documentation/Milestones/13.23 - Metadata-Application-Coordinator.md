# Milestone 13.23

## Coordinador productivo de aplicación de metadatos

## Objetivo

Incorporar un punto de entrada productivo, único y reutilizable para ejecutar una solicitud aprobada mediante el pipeline modular completo de aplicación de metadatos.

El coordinador desacopla a los consumidores del proceso interno de creación del contexto, composición del pipeline, ejecución de etapas, tratamiento de cancelaciones y construcción del resultado final.

## Alcance

Este milestone incorpora:

* el contrato `IMetadataApplicationCoordinator`;
* la implementación `MetadataApplicationCoordinator`;
* la creación automática del contexto de ejecución;
* el uso de la composición predeterminada de cinco etapas;
* la ejecución completa mediante un único método;
* el tratamiento controlado de cancelaciones;
* el tratamiento de fábricas y ejecutores inválidos;
* la traducción de fallos a razones de detención auditables;
* pruebas controladas sin acceso a archivos de audio;
* integración temporal de las pruebas en el diagnóstico técnico;
* revalidación integral aislada sobre un archivo FLAC.
