# Milestone 13.13 — Fase B

## Refactor de TagLibIsolatedWriteTestRunner

## Objetivo

Refactorizar `TagLibIsolatedWriteTestRunner` para eliminar la lógica
duplicada de aislamiento de archivos y utilizar la infraestructura
común creada durante la Fase A.

El comportamiento funcional de las pruebas aisladas debía mantenerse
sin cambios.

## Problema anterior

`TagLibIsolatedWriteTestRunner` era responsable simultáneamente de:

- validar el escritor;
- crear la carpeta temporal;
- crear la copia de trabajo;
- crear el respaldo;
- calcular hashes SHA-256;
- comprobar la integridad del archivo original;
- comprobar la modificación de la copia;
- ejecutar el escritor TagLibSharp;
- verificar los metadatos persistidos;
- verificar las imágenes incrustadas;
- construir el resultado final.

Esto mezclaba responsabilidades de infraestructura con lógica
específica de TagLibSharp y duplicaba funcionalidad que también será
necesaria para futuras pruebas de integración.

## Solución implementada

El runner ahora utiliza `FileIsolationTestHarness`.

El flujo actualizado es:

1. El runner valida la ruta, el formato y el escritor.
2. `FileIsolationTestHarness.CreateAsync()` crea:
   - la carpeta temporal;
   - la copia de trabajo;
   - el respaldo;
   - los hashes SHA-256 iniciales.
3. El runner abre la copia y obtiene:
   - género original;
   - cantidad inicial de imágenes.
4. El escritor real modifica únicamente la copia.
5. El runner vuelve a abrir la copia mediante TagLibSharp.
6. El runner verifica:
   - género persistido;
   - conservación de imágenes.
7. `FileIsolationTestHarness.VerifyAsync()` comprueba:
   - archivo original intacto;
   - respaldo idéntico al estado inicial;
   - copia de trabajo modificada.
8. El runner construye `TagLibIsolatedWriteTestResult`.

## Responsabilidades actuales

### FileIsolationTestHarness

Responsable de:

- crear el entorno temporal;
- copiar el archivo original;
- crear el respaldo independiente;
- calcular hashes SHA-256;
- verificar la integridad del original;
- verificar el respaldo;
- detectar la modificación de la copia;
- permitir la limpieza del entorno temporal.

### TagLibIsolatedWriteTestRunner

Responsable de:

- validar la compatibilidad del escritor;
- leer los metadatos originales;
- construir `MetadataWriteRequest`;
- ejecutar el escritor;
- reabrir el archivo;
- verificar el género persistido;
- verificar las imágenes;
- construir el resultado específico de la prueba.

## Compatibilidad mantenida

La API pública del runner se mantiene:

- `RunAsync(...)`
- `TagLibIsolatedWriteTestResult`

Los wrappers existentes para MP3 y FLAC pueden continuar utilizando
el runner sin cambios funcionales.
