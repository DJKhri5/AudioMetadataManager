# Milestone 13.38 - Reversible and Safe File Renaming

## Objetivo

Transformar la pestaña de `Renombrado` de archivos en un flujo de ejecución
productivo, seguro y completamente reversible, incorporando saneamiento según
las normas del sistema de archivos Windows, detección estricta de colisiones,
comprobación preventiva de bloqueos y una bitácora transaccional con reversión.

## Alcance

El motor de renombrado seguro incorpora:

- `SafeFileNameSanitizer`: eliminación y sustitución de caracteres prohibidos
  en Windows (`\ / : * ? " < > |`), eliminación de puntos o espacios al final
  del nombre base, y protección frente a nombres de dispositivos reservados
  del sistema operativo (`CON`, `PRN`, `AUX`, `NUL`, `COM1-9`, `LPT1-9`).
- `FileRenameCollisionDetector`: detección exhaustiva de colisiones en disco
  (archivos existentes en la misma carpeta) y colisiones intra-lote (dos o más
  archivos que generarían el mismo destino).
- `FileRenameService`: ejecución física mediante `File.Move`, cálculo de hash
  SHA-256 pre/post operación, bitácora en memoria (`RenameJournalEntry`) y
  capacidad de reversión (*rollback*).
- Integración en la interfaz de usuario: en la pestaña `Renombrado`, se muestra
  el nombre actual, el nombre propuesto, el nombre saneado para Windows y el
  diagnóstico de seguridad, con confirmación explícita e independiente de la
  escritura de metadatos.

## Reglas de seguridad

- El renombrado físico nunca sobreescribe un archivo existente en disco.
- Se comprueba la disponibilidad exclusiva del archivo (*file lock check*) antes
  de intentar moverlo.
- Se conserva y normaliza la extensión original (`.mp3`, `.flac`, etc.) a
  minúsculas.
- Se limita la longitud total de la ruta para evitar errores con `MAX_PATH` (260
  caracteres).
- Un nombre idéntico al actual se clasifica como `NoOp` y no ejecuta llamadas a
  disco innecesarias.
- Cada renombrado exitoso registra el hash SHA-256 original y la ruta previa en
  la bitácora transaccional para permitir restaurar el nombre original en caso
  de necesidad.
