# Milestone 13.30

## Instalador real de Windows

## Objetivo

El usuario pidió un "instalable" — no un ejecutable portable suelto,
sino un instalador real con asistente, que copie la app a Archivos de
Programa, cree accesos directos en el menú inicio y aparezca en
"Agregar o quitar programas", como cualquier programa de Windows.

## Herramienta elegida: Inno Setup

Se evaluaron dos alcances con el usuario: ejecutable portable de un
solo archivo, o instalador real. Se eligió el instalador real. Inno
Setup se eligió por ser gratuito, ampliamente usado, scriptable con un
formato de texto simple (`.iss`), y compilable enteramente por línea
de comandos (`ISCC.exe`) — lo que permite verificar el resultado sin
necesitar abrir ninguna ventana del asistente de instalación.

Se instaló mediante `winget install --id JRSoftware.InnoSetup -e`.

## Componentes incorporados

### installer/AudioMetadataManager.iss

Script de Inno Setup que:

- toma como entrada el ejecutable autocontenido de un solo archivo ya
  publicado en `publish/AudioMetadataManager/AudioMetadataManager.UI.exe`
  (no publica nada por sí mismo);
- instala en `{autopf}\Audio Metadata Manager` (Archivos de Programa,
  sensible a instalación de 64 bits);
- crea accesos directos en el menú inicio y un desinstalador;
- ofrece como tarea opcional (sin tildar por defecto) un acceso
  directo en el escritorio;
- registra el instalador en español (`compiler:Languages\Spanish.isl`).

### build-windows.ps1 (corregido)

El script tenía referencias rotas: apuntaba a `AudioMetadataManager.sln`
en la raíz (no existe; la solución real es `src/AudioMetadataManager.slnx`)
y a `src/AudioMetadataManager/AudioMetadataManager.csproj` (no existe;
el proyecto real es `src/AudioMetadataManager.UI/AudioMetadataManager.UI.csproj`),
y ejecutaba `dotnet test` contra una solución sin ningún proyecto de
pruebas.

Se corrigieron las rutas, se quitó el paso de pruebas inexistente, y
se agregó un paso final: si Inno Setup está instalado, compila
automáticamente el instalador después de publicar; si no lo está,
informa cómo instalarlo sin fallar el resto del script.

### README.md

Corregido en la misma pasada: mencionaba una solución y un proyecto
que no existen, y afirmaba que la app estaba en "Modo Simulación" sin
escribir archivos — ya no es cierto desde hace varios milestones. Se
actualizó para reflejar el estado real y documentar el instalador.

## Verificación

Se verificó todo el camino sin necesitar abrir ninguna ventana:

1. `dotnet publish` produjo un `.exe` autocontenido (~163 MB). Se
   ejecutó brevemente y se confirmó que el proceso permanece vivo
   (no se cae al iniciar).
2. `ISCC.exe` compiló el instalador sin errores (~50 MB tras
   compresión LZMA2).
3. **Instalación silenciosa de prueba** (`/VERYSILENT /DIR=<carpeta
   temporal>`), para no tocar el sistema real durante la verificación:
   el ejecutable se copió correctamente al destino indicado.
4. **Hallazgo durante la verificación**: aunque `/DIR` apuntaba a una
   carpeta temporal aislada, Inno Setup igualmente creó accesos
   directos reales en el menú inicio del sistema
   (`C:\ProgramData\Microsoft\Windows\Start Menu\Programs\Audio Metadata Manager\`)
   y una entrada real en el registro
   (`HKEY_LOCAL_MACHINE\...\Uninstall\{B3B6B6D4-...}_is1`), visible en
   "Agregar o quitar programas" del sistema real del usuario. Esto es
   el comportamiento esperado de un instalador real (no es un defecto
   del script), pero significaba que la prueba había dejado rastros
   reales en el sistema.
5. Se corrigió de inmediato ejecutando el desinstalador generado
   (`unins000.exe /VERYSILENT`) y se confirmó explícitamente: la clave
   de registro ya no existe, la carpeta del menú inicio ya no existe,
   y la carpeta de archivos de la app quedó vacía. El sistema del
   usuario quedó exactamente como estaba antes de la prueba.
6. Se corrió `build-windows.ps1` completo (no sólo los pasos por
   separado) para confirmar que el script corregido funciona de
   principio a fin: publica y compila el instalador en una sola
   ejecución.

## Estado

- Implementación completa: instalador real funcional.
- Publicación, compilación e instalación/desinstalación silenciosas
  verificadas de extremo a extremo.
- Rastros dejados durante la propia verificación (acceso directo y
  entrada de registro) fueron detectados y revertidos en la misma
  sesión.
- `build-windows.ps1` y `README.md` corregidos; ya no referencian
  rutas inexistentes.
- Pendiente de que el usuario confirme visualmente el asistente de
  instalación (ventanas del wizard, textos en español) — no puede
  verificarse sin abrir una ventana en este entorno.
- Milestone completado.
