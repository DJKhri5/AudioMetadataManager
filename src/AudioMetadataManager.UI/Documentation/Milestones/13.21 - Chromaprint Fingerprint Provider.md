# Milestone 13.21

## Proveedor de huellas acústicas Chromaprint

## Objetivo

Incorporar la generación local de huellas acústicas mediante el
ejecutable externo `fpcalc` (Chromaprint), como primer paso hacia la
identificación automática de pistas antes de consultar fuentes externas
de metadatos.

Esta versión únicamente genera la huella y la duración informadas por
`fpcalc`. No consulta todavía la API pública de AcoustID ni ninguna otra
fuente externa.

## Componentes incorporados

### ChromaprintOptions

Configuración necesaria para invocar `fpcalc`: ruta del ejecutable
(por defecto disponible en el PATH del sistema) y tiempo máximo de
espera.

### ChromaprintStatus

Enumera los estados posibles de una generación de huella: `Success`,
`InvalidRequest`, `InvalidConfiguration`, `ExecutableNotFound`,
`ProcessError`, `Timeout`, `Cancelled`, `InvalidOutput` y
`UnexpectedError`.

### ChromaprintFingerprintRequest / ChromaprintFingerprintResult

Modelos normalizados de entrada y salida, con factorías estáticas
(`InvalidRequest`, `InvalidConfiguration`, `ExecutableNotFound`) que
siguen el mismo patrón ya utilizado por `DiscogsSearchResult`.

### ChromaprintProcessOutputDto

Representa la salida JSON entregada por `fpcalc -json`
(`duration` y `fingerprint`).

### ChromaprintFingerprintExecutor

Invoca `fpcalc` como proceso externo y produce un resultado
normalizado.

El ejecutor:

- valida que el archivo indicado exista y que la configuración sea
  válida antes de iniciar el proceso;
- construye los argumentos del proceso mediante `ArgumentList` en
  lugar de concatenar una cadena de comando, evitando así inyección de
  argumentos a través de nombres de archivo con comillas o espacios;
- distingue explícitamente entre cancelación solicitada por el
  usuario y expiración del tiempo máximo configurado, devolviendo
  `Cancelled` o `Timeout` según corresponda;
- finaliza el proceso (`Kill(entireProcessTree: true)`) cuando se
  cancela o expira, y descarta de forma segura las tareas de lectura
  de salida pendientes para evitar excepciones no observadas;
- interpreta la salida JSON y valida que contenga una huella no
  vacía antes de reportar éxito.

### ChromaprintFingerprintDiagnostics

Ejecuta la generación de huella sobre un archivo real y construye un
informe legible con el estado, la duración, el código de salida y la
huella obtenida. Pensado para verificación manual, no para pruebas
automatizadas.

## Correspondencia de resultados

- Huella generada con contenido válido: `Success`.
- Archivo inexistente o ruta vacía: `InvalidRequest`.
- Configuración inválida (ruta o tiempo de espera): `InvalidConfiguration`.
- `fpcalc` no pudo iniciarse: `ExecutableNotFound`.
- `fpcalc` terminó con código distinto de cero: `ProcessError`.
- El proceso no terminó dentro del tiempo configurado: `Timeout`.
- La operación fue cancelada por el token del llamador: `Cancelled`.
- La salida no pudo interpretarse o no contiene huella: `InvalidOutput`.

## Decisión arquitectónica

Chromaprint no se registró como `IMetadataSource` ni se incorporó a
`MetadataSourceFactory`. Su responsabilidad es distinta a la de una
fuente de búsqueda de metadatos: genera un identificador acústico
local que servirá como entrada de una consulta posterior a AcoustID,
no un conjunto de candidatos de metadatos por sí mismo.

## Verificación

No se agregó un ejecutor de pruebas estructurales equivalente al de
las etapas del pipeline de aplicación (`Testing/PipelineStages/...`),
ya que el resto de los proveedores de `MetadataSources/Providers`
(Discogs incluido) tampoco lo utiliza; esa ceremonia es específica del
subsistema `Simulation.Application`.

El código fue revisado manualmente contra las APIs de .NET 8 del
proyecto (`Process.WaitForExitAsync(CancellationToken)`,
`StreamReader.ReadToEndAsync(CancellationToken)`,
`Process.Kill(bool)`).

La verificación inicial se hizo sin el SDK de `dotnet` instalado en la
máquina de desarrollo. Tras instalar el SDK de .NET 8 (`8.0.423`), se
ejecutó `dotnet build` sobre `AudioMetadataManager.UI.csproj` y se
detectó un único error real: `ChromaprintFingerprintExecutor` usaba
`File.Exists` sin el `using System.IO;` correspondiente (el proyecto,
al tener `UseWPF=true`, no incluye ese namespace entre los usings
implícitos). Se agregó el `using` faltante y la compilación quedó
limpia.

Sigue pendiente una prueba manual con un archivo de audio real y
`fpcalc` instalado, ya que este entorno no tiene el ejecutable
disponible.
