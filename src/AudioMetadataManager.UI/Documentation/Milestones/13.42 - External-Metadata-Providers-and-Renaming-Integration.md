# Hito 13.42: Proveedores Externos de Metadatos y Vinculación Reactiva con Renombrado Seguro

## 1. Contexto y Objetivos

Para enriquecer los metadatos locales y corregir nombres de archivo inconsistentes o truncados, la aplicación requiere consultar múltiples plataformas externas de datos musicales (MusicBrainz, Beatport, SoundCloud, Spotify y Discogs).

Un requisito fundamental de este hito es que los metadatos canónicos obtenidos por las fuentes externas no queden aislados en diagnósticos de texto, sino que se vinculen reactivamente con el modelo de simulación (`audioFile.Simulation`) para que la pestaña **Renombrado** (individual y por lote) reciba de inmediato los nombres propuestos canónicos (ej. `Artista - Título (Versión).ext` o `Artista - Título.ext`).

---

## 2. Componentes Implementados

### 2.1. Proveedores Externos de Metadatos
- **MusicBrainz (`MusicBrainzMetadataProvider` / `MusicBrainzMetadataSource`):**
  - Conexión con la API pública abierta de MusicBrainz v2 (`https://musicbrainz.org/ws/2/recording`).
  - No requiere clave de API (usa cabecera `User-Agent` de cortesía).
  - Extrae artista canónico, título oficial, álbum, sello discográfico, año y duración.
- **Beatport (`BeatportMetadataProvider` / `BeatportMetadataSource`):**
  - Especializado en música electrónica, mezclas (*Extended Mix, Original Mix, Dub Mix*), remixers y sellos de club.
- **SoundCloud (`SoundCloudMetadataProvider` / `SoundCloudMetadataSource`):**
  - Especializado en bootlegs, remixes no oficiales, mashups y producciones independientes.
  - Asigna la bandera de seguridad `RequiresManualApproval = true`.
- **Spotify (`SpotifyMetadataProvider` / `SpotifyMetadataSource`):**
  - Catálogo de streaming para artista principal, colaboradores y títulos oficiales.
- **Factoría (`MetadataSourceFactory`):**
  - Registra a MusicBrainz como fuente primaria junto a Discogs, Beatport, Spotify y SoundCloud.

### 2.2. Puente de Sincronización con Renombrado (`SimulationPlanToRenamingSynchronizer`)
- Ubicación: `src/AudioMetadataManager.UI/Services/Simulation/SimulationPlanToRenamingSynchronizer.cs`
- Responsabilidades:
  1. Extrae los valores canónicos seleccionados de `MetadataChangePlan` o `SimulationPlanViewModel` para `Artist`, `Title`, `Version` y `Label`.
  2. Genera el nombre de archivo canónico formateado y validado con `SafeFileNameSanitizer`.
  3. Actualiza el modelo `audioFile.Simulation` y notifica a las vistas de simulación y renombrado.
- Integrado en `MainWindow.xaml.cs`:
  - Se ejecuta automáticamente tras el análisis externo y consenso.
  - Se ejecuta reactivamente al modificar valores o casillas en la pestaña **Metadatos**.
  - Actualiza el contexto de la pestaña **Renombrado** (`RenamePreviewViewControl`) y la tabla de la biblioteca en tiempo real.
